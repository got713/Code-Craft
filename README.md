# CodeCraft Studio Landing Page

Official responsive, bilingual landing page for **CodeCraft Software & Digital Solutions** built with React, Vite, and Tailwind CSS v4.0.

## Tech Stack
- **Core**: React 19 (JavaScript ESM)
- **Styling**: Tailwind CSS v4.0 (Native @theme variable architecture)
- **Animation**: Motion (`motion/react`)
- **Iconography**: Lucide React

## Features
- **Bilingual Interface**: Seamlessly toggles between Arabic (`rtl`) and English (`ltr`) with auto-adjusting page flows.
- **Ambient GPU Animations**: Floating vector visual graphs and ambient glows using native CSS radial gradients to ensure smooth, hardware-accelerated 60fps scrolling.
- **Scroll Progress Indicator**: High-end physics-based reading progress line fixed under the Navbar.
- **Floating Contact Points**: Ambience-pulsing floating WhatsApp button with pre-filled professional inquiries.
- **Interactive Mockups**: Vector-rendered administrative, mobile, and web layouts embedded inside the portfolio showcase.
- **SEO & Responsiveness**: Clean markup, structured header tags, meta description details, and full mobile-fluid responsiveness.

## Development

Install dependencies:
```bash
npm install
```

Run local development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```
